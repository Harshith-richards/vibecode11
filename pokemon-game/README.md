# PokéLite RPG

## Setup
1. Open `pokemon-game/index.html` directly in a modern browser.
2. Optional (recommended for stricter browser security):
   - Run `python3 -m http.server 4173` from repository root.
   - Visit `http://localhost:4173/pokemon-game/`.

## Notes
- Save data is stored in `localStorage` under `pokelite-save-v1`.
- If PokeAPI is unavailable, starter fallback data is still playable.
